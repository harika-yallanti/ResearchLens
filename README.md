# AI Research Paper Quality Analyzer

An AI-powered web application designed to evaluate academic research
papers using Artificial Intelligence and Natural Language Processing.

## Technology Stack

- Python
- FastAPI
- MySQL
- SQLAlchemy
- Groq API
- HTML, CSS, JavaScript
- Jinja2

## Features

- User authentication
- Research paper upload
- AI-powered paper analysis
- Research quality scoring
- Writing quality evaluation
- Citation consistency checking
- Research paper summarization
- Downloadable assessment reports
